# FreshMart: Sales, Profit & Customer Performance Analytics Dashboard

A comprehensive **end-to-end Power BI dashboard** for FreshMart, India's leading retail hypermarket chain, providing deep insights into sales trends, profitability analysis, product performance, customer behaviour, and store/delivery operations across India.

> 📊 Power BI Desktop | 5 report pages | 3 years of data (2023-2025) | Multi-dimensional retail analytics | 500K+ transactions

---

## 📌 Project Overview

FreshMart is one of India's largest retail hypermarket chains, selling groceries, food, beverages, apparel, footwear, electronics, personal care, and home & kitchen products across the country. This dashboard provides a **360° view** of business performance, enabling category managers, store heads, and leadership to make faster, data-backed decisions on inventory, pricing, marketing, and store operations.

**Dataset Scope:**
- **510,000 total orders** across 90 FreshMart stores
- **58 cities across 40 states** (77 unique cities covered)
- **6,000 products** in 25 categories and 117 sub-categories
- **56 brands** represented
- **3-year span:** January 2023 – December 2025

## 🚀 How to Use

### Prerequisites
- **Power BI Desktop** (free download from [Microsoft](https://powerbi.microsoft.com/en-us/desktop/))

### Steps
1. **Extract the project files**
   ```
   freshmart-dashboard/
   ├── README.md
   ├── LICENSE
   ├── freshmart_sales_analysis.pbix
   └── screenshots/
   ```

2. **Open the dashboard in Power BI Desktop**
   - Double-click `freshmart_sales_analysis.pbix`
   - Or: File → Open → Select .pbix file

3. **Navigate & Explore**
   - Move between 5 pages (buttons at bottom)
   - Use slicers to filter by Year, State, Category, etc.
   - Hover over charts for drill-down values

4. **Interact with Visuals**
   - Click on bars/segments for cross-filtering
   - Use back/forward arrows for drill-through
   - Export specific visuals as needed
